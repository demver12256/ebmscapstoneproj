# Frontend - React.js

## Setup

1. Install dependencies:
```bash
npm install
```

2. Configure API endpoint:
   - Update `REACT_APP_API_URL` in `.env` file
   - Default: http://localhost:5000

3. Run the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- Axios for API calls
- Create React App
- Proxy configured for backend API

## API Integration

The `services/api.js` file handles all API calls to the backend.
